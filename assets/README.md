# Testiaineistot

Lisää tähän kansioon testikuvat ja -videot:

## Kuvat
- `test-image.jpg` — JPG-testikuva, 1920×1080, esim. mainosmateriaali tai testikuva
- Tuetut formaatit: JPG, PNG

## Videot
- `test-video.mp4` — MP4-testivideo (H.264), max 6s, muted
- Tuetut formaatit: MP4 (H.264)
- **Huom:** Pidä videot pieninä (< 10 MB) — ladataan verkon yli

## Ohjeet
1. Nimeä tiedostot yllä olevien nimien mukaisesti TAI muokkaa `index.html`-tiedoston PLAYLIST-taulukkoa
2. Kuvien ja videoiden tulee olla 1920×1080 (landscape)
3. Videot eivät saa sisältää ääntä (tai ne mykistetään automaattisesti)

Jos tiedostoja ei löydy, näytetään automaattisesti Proscreen-brändätty fallback-kuva.
