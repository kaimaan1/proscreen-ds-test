====================================
Paeivaeys: 2026-03-10

1. YLEISKUVAUS
--------------
HTML5-diaesityssovellus BrightSign LS424 -mediasoittimelle. Kaeytetaeaen
digital signage -sisaelloen esittaemiseen LED-naeytoellae. Deployataan GitHub
Pagesin kautta, laite lataa sisaelloen verkko-URL:sta.

Paeaekaeytti: tekniikan validointi (renderoeinti, vakaus, muistinhallinta).
Nykyisin myoes tuotantokaeytoessae asiakkaan ZIP-sisaelloillae.

6. GRACEFUL UPDATE -MEKANISMI
-----------------------------
Estaeae violetin ruudun ja osittaisen paeivityksen ongelmat.

VERSION-tunniste:
  - Koodissa: var VERSION = '__BUILD_TIMESTAMP__';
  - CI korvaa deployn yhteydessae muotoon YYYYMMDD-HHMMSS
  - Paikallisessa kehityksessae jaeae placeholderiksi (ei triggeroeidy)

Cache-busting (bustCache-funktio):
  - Kaikki paikalliset resurssit (kuvat, videot, iframet) saavat
    URL-parametrin ?_v=<VERSION>
  - Ulkoisiin URLeihin ei kosketa

Paeivitystarkistus (2 min vaeelin):
  1. Haetaan oma index.html fetch:llae (cache: no-store)
  2. Poimitaan VERSION regex:llae vastauksesta
  3. Jos eri kuin nykyinen -> prepareUpdate()
  4. XHR-fallback jos fetch ei tuettu (BrightSign)

Preload piilotetussa iframessa:
  1. Luodaan naekymaetoen iframe (?noupdate=true)
  2. Iframe lataa koko uuden version + triggeroeie resurssien latauksen
  3. noupdate=true estaeae rekursiivisen paeivitystarkistuksen

Vaihto slidejen vaelissae:
  1. nextSlide() tarkistaa pendingUpdate-lipun
  2. Jos paiv. odottaa: fade-out 0.8s -> window.location.href cache-bustilla
  3. Turvamekanismi: 2 min timeout pakottaa vaihdon
  4. Katsoja naekkee vain tumman taustan slidejen vaelissae

8. DIAGNOSTIIKKA
----------------
Aktivointi: ?debug=true URL-parametri

Naeytettaevae tieto:
  - Uptime (pv h min s)
  - Luuppikierrokset (monta kertaa playlist on pyoerinyt)
  - Aika (fi-FI locale)
  - Muisti MB (JS heap used/total, jos saatavilla)
  - Viim. vaihto (kellonaika)
  - Nykyinen slot (esim. "3/10 - Testivideo")
  - Versio (VERSION-tunniste)
  - Paeivitys ("OK" / "Ladataan..." / "Odottaa vaihtoa")

Paeivietetaeaen 1s vaeelin (setInterval).
Overlay: oikeassa alakulmassa, laepinaekyva musta tausta, vihreae teksti.


9. VIRHEENKAESITTELY
--------------------
window.onerror:
  - Naeyttaeae PROSCREEN-fallback-naeytoet 5s
  - Yrittaeae palauttaa diaesityksen
  - Jos palautus epaeonnistuu: window.location.reload()

window.onunhandledrejection:
  - Estaeae Promise-virheiden kuplimisen
  - Naeyttaeae fallbackin 5s

Auto-reload (klo 03:00):
  - Vain jos uptime > 4h (estaeae looppi)
  - Graceful fade-out -> cache-bustattu reload
  - Tarkistetaan 30s vaeelin

Slide-fallback:
  - Jos kuva/video ei lataudu, naeyttaeae canvas-fallbackin
    (violetti tausta + "Aineisto ei saatavilla" -teksti)
